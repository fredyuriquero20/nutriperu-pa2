# NutriPeru — MVP PA2
Tienda demostrativa de suplementos deportivos.

## Publicación en GitHub Pages
1. Crea un repositorio público llamado `nutriperu-pa2`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz.
3. En GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. La URL suele ser `https://TU-USUARIO.github.io/nutriperu-pa2/`. Espera a que GitHub confirme la publicación.
5. Abre la URL desde un teléfono real y prueba navegación, búsqueda, filtros, carrito, formularios y enlaces.

## Antes de usarlo comercialmente
- Reemplaza los enlaces `wa.me` genéricos por el número oficial de WhatsApp Business (solo dígitos, formato internacional).
- Los productos y precios son de muestra. No hay inventario, pedidos ni pagos reales en servidor.
- Geolocalización solicita permiso y solo demuestra la captura de coordenadas; no calcula flete.
- Verifica proveedor, etiquetas, requisitos regulatorios, términos y política de privacidad antes de vender.
